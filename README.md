# ChainStack

ChainStack is a distributed, data-driven processing framework with event-driven architecture and a scalable manager-node topology.

The key benefits of using ChainStack include:

- ChainStack is a distributed, data-driven
- processing framework with event-driven architecture
- and a scalable manager-node topology

## Technology Stack

- javascript

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/ChainStack.git`
2. `cd ChainStack`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
